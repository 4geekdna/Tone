Settings help
Speed
How fast blobs and rings move. 0.5–1.2 feels calm; higher is more energetic.
React
How strongly the loudest frequencies punch through. Lower = more even; higher = more dramatic peaks.
Adapt
How quickly the visual follows changes in the sound. Lower = smoother; higher = snappier.
Variance
How much the loudest band pulls the color mix. Higher = more color contrast.
Blend
Base amount of mixing between the dominant color and the others. Higher = more blended; lower = purer single color.
Strength
Size of blobs and rings. Higher = bigger shapes.
Darkness
How dark the bottom of the gradient is. Higher = deeper background.
Bands
Number of frequency bands analyzed (1–7). 7 uses all chakras.
Chakra lock
Forces the color to the current chakra based on video time instead of the loudest band.
Look
Wash = full-screen gradient only. Blobs = floating colored circles. Rings = concentric rings from the center.
Peaks mode
Keeps the visualization running even when the video is paused.
Source
Built-in bowl video, a library file, or an in-place file. Same library as the main journey.

Quick starts
Calm wash: Look = Wash, Chakra lock = On, Blend 0.7–0.9, React 1.0–1.4.
Active blobs: Look = Blobs, Strength 1.2+, Variance 0.6+, Adapt 0.4+.
Rings: Look = Rings, Bands = 7, Strength 1.0–1.3.

Settings save automatically on this device. The big button toggles Play/Pause. Tap the thumbnail to hide it.
